# Halo 视角 · 车手头盔 4 秒分镜

机位：halo 前立柱上，镜头朝后，正对车手面罩；背景是向后飞退的黄昏赛道。9:16，无音乐，只有引擎 + 风噪。

| 时间 | 画面 |
|---|---|
| 0.0–1.5s | 平稳直线，头盔轻微呼吸起伏，面罩反射赛道余光 |
| 1.5–2.1s | 路面颠簸，头盔下点，画面抖动 |
| 2.1–2.8s | 面罩撕膜，膜片飘走 |
| 2.8–3.5s | 车手转头 |
| 3.5–4.0s | 回正，镜头继续后拉 |

渲染：`python3 video/race.py --halocam --dusk`（静帧加 `--still <t>`）
