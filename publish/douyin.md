## 1. 和横版的区别

- 画面从**起跑灯亮起的第一帧**开始（前几秒静止的发车格已去掉），总长仍是 128 秒。
- 为了补回开头去掉的 5.6 秒，结尾延长了：冲线后有一段慢速滑行和片名再现，音乐尾声同步延长。
- 左上角有**名次显示**（P6 → P1，每次超车数字变橙弹一下，冲线后显示 WINNER），竖屏观众一眼能看懂剧情。
- 为避开抖音界面，Claude 标志放在左上，右侧和底部不放文字。

## 1b. 16 秒预告片版（方案 B：爆点前置 + 循环）

`video/redline_teaser.mp4`（1080×1920，16 秒，29MB）。分镜见 `publish/teaser_storyboard.md`：
0 秒座舱 REDLINE 钩子（「F1 RACING」砸入）→ 1.6 秒高潮重击 + 超车 → 赛道边呼啸 → 追拍、超车 #2 → 座舱回闪 → 起跑闪回（灯灭起步）→ 终点直道（红车并排、挥白旗）→ 14.4 秒硬切赛道边呼啸 + 「WIN」。
**全程无字幕，只有开头「F1 RACING」和结尾「WIN」**（粗斜体，Barlow Condensed Black Italic）。尾音接回开头的上升音效，适合循环播放。
建议和完整版配合：预告片先发引流，评论区/置顶放完整版；也可以和上一版（方案 A）错开发，比较 3 秒留存和完播率。
文案可用「灯灭那一刻，转速拉到红线🏁 一路超车到冠军 #F1 #赛车 #AI生成」；置顶评论「你觉得红车输在哪儿？👇」。
