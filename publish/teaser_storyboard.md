## 3. 平台检查表

- [x] **前 1 秒**：有声音爆点（上升扫频收尾）+ 强视觉冲突（指针冲进红区）
- [x] **1.6 秒内**兑现第一个爆点（高潮重击 + 超车）
- [x] **镜头节奏**：平均 1.6 秒一个镜头，每 2 小节至少一次明显变化（机位、景别或速度）
- [x] **回钩**：7.2 秒重复钩子画面，加深记忆点
- [x] **结尾**：WIN 压在重击的余音上，留白，尾音接回开头，利于循环（增加重复观看）
- [x] **字幕**：全程只有 F1 RACING / WIN；互动靠置顶评论，不靠画面文字
- [x] **安全区**：字幕在天空区，避开抖音顶部状态栏、右侧按钮和底部 20% 文案区
- [x] **声音优先**：第一帧就有声音，不依赖字幕理解

## 4. 与发布配合

- **封面**：用 `publish/cover_douyin_9x16.png`；视频第一帧本身就是钩子，不需要靠封面补。
- **文案**（≤55 字）：`灯灭那一刻，转速拉到红线🏁 一路超车到冠军 #F1 #赛车 #AI生成`
- **置顶评论**：`你觉得红车输在哪儿？👇` 或 `第几秒最燃？`（用评论数撑互动）
- **A/B 测试**：两个版本（A 当前版 / B 重排版）错开几小时分别发，比较 3 秒留存和完播率，用数据选。
- **声明**：勾选「内容由AI生成」，不另加平台音乐。

## 5. 制作量

方案 B 的镜头里，只有第 3、10 个（赛道边呼啸）是新的，其余都是已有素材，按拍点重新剪排：重渲约 10–15 分钟，叠字幕和音效约 2 分钟。
